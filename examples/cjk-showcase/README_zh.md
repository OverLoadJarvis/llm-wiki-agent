# CJK 展示案例（中文语言示例）

本目录展示了 LLM Wiki Agent 如何处理非英语（CJK）语言内容。

Agent 原生支持中文内容的处理。随着 CJK 查询问题的修复，你可以无需任何语言特定配置，即可完成中文词条的摄取、查询和语言检索。

## 本展示案例包含的文件：

- `raw/2026-04-13-reflection.md`：示例源文档（一份关于职业转型的个人反思）。
- `wiki/sources/2026-04-13-reflection.md`：解析后的结构化源页面。
- `wiki/entities/杨帆.md`：自动提取的中文实体页面。
- `wiki/concepts/AI转型.md`：自动提取的中文概念页面。

将上述文件移至你的主要知识库后，可尝试从根目录运行 `python tools/query.py "关于AI转型的建议"`，以了解语义提取和关键词匹配在非英语语境下的表现！
